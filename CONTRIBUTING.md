# Contributing

This repository is owner-controlled.

Before merging a material change:
- preserve authorship, provenance, and source lineage;
- do not replace canonical source with regenerated code when authentic source exists;
- keep claims within the documented evidence ceiling;
- add or update tests for executable changes;
- keep secrets, personal data, and restricted third-party material out of Git;
- use pull requests after the canonical source-import baseline is established.
